# LoCoMo data

Download `locomo10.json` from the
[official LoCoMo repository](https://github.com/snap-research/locomo) and
place it in this directory:

```text
benchmarks/locomo/data/locomo10.json
```

The LoCoMo dataset is distributed under
[CC BY-NC 4.0](https://github.com/snap-research/locomo/blob/main/LICENSE.txt).
It is not included in MiniMem.
