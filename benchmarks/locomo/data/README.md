# LoCoMo data

This directory includes an unmodified copy of `locomo10.json` from the
[official LoCoMo repository](https://github.com/snap-research/locomo):

```text
benchmarks/locomo/data/locomo10.json
```

LoCoMo was created by Adyasha Maharana, Dong-Ho Lee, Sergey Tulyakov,
Mohit Bansal, Francesco Barbieri, and Yuwei Fang for the paper
["Evaluating Very Long-Term Conversational Memory of LLM Agents"](https://arxiv.org/abs/2402.17753).

The dataset is distributed under
[CC BY-NC 4.0](https://github.com/snap-research/locomo/blob/main/LICENSE.txt)
and is intended for non-commercial use. This dataset license is separate from
MiniMem's MIT license.
