# Contributing

Thank you for contributing to MiniMem.

Please keep changes aligned with the project's intentionally small scope:

- LLM-only memory construction
- direct embedding top-k retrieval
- single-question conversational memory evaluation
- clear, provider-neutral code

Before opening a pull request:

1. Keep source comments, documentation, and user-facing messages in English.
2. Do not add API keys, generated memories, predictions, or third-party data.
3. Run the synthetic quickstart after behavior changes.

Please open an issue before proposing clustering, reranking, graph retrieval,
memory update policies, or other features outside the baseline scope.
